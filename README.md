# ModGenePlexus

This GitHub repository contains the main ModGenePlexus code, with emphasis on the study-biased holdout analyses. It is meant to be a snapshot of the code.

The complete archival research snapshot, including additional code, data, figures, and large result files, is available on Zenodo:

https://doi.org/10.5281/zenodo.19857910

## Repository Contents

- `pygeneplexus/`: GenePlexus Python code used as part of the ModGenePlexus workflow.
- `src/`: Main ModGenePlexus analysis scripts.
- `src/diabetes/`: Type 2 diabetes case-study scripts.
- `figures/`: Figure assembly scripts and selected figure outputs.
- `tsne/`: Network embedding visualization scripts and selected outputs.

## Reuse Notes

This code was developed for the analyses in the associated study. Some scripts assume the original file paths and compute environment. The Zenodo record contains the larger analysis archive and result files.
